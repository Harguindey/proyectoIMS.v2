# VentasPro — Ventas, Clientes y Punto de Venta

**Producto independiente** extraído de la Suite LogiPro.

## Qué incluye

| Módulo | Ruta |
|---|---|
| Dashboard | `/` |
| Punto de Venta (TPV) | `/pos` |
| Clientes | `/customers` |
| Pedidos | `/orders` |
| Reservas | `/reservations` |
| CRM | `/erp/crm` |
| Facturas | `/erp/invoices` |
| Reportes | `/reports` |
| Configuración / Equipo / Facturación | `/settings` `/team` `/billing` |

## Cómo arrancar

```bash
cp products/ventas-pro/.env.example .env
npm run dev
```

## Color de marca

- Primario: Verde `hsl(151, 55%, 42%)`
- Ideal para tiendas, comercios y equipos de ventas
