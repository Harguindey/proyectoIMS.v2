# ERPSuite — Suite ERP Empresarial

**Producto independiente** extraído de la Suite LogiPro.

## Qué incluye

| Módulo | Ruta |
|---|---|
| Dashboard | `/` |
| Facturación | `/erp/invoices` |
| Compras ERP | `/erp/purchases` |
| Contabilidad | `/erp/accounting` |
| CRM | `/erp/crm` |
| RRHH | `/erp/hr` |
| Cumplimiento Fiscal | `/erp/fiscal` |
| Clientes | `/customers` |
| Proveedores | `/suppliers` |
| Reportes | `/reports` |
| Configuración / Equipo / Facturación | `/settings` `/team` `/billing` |

## Cómo arrancar

```bash
cp products/erp-suite/.env.example .env
npm run dev
```

## Color de marca

- Primario: Índigo `hsl(243, 75%, 56%)`
- Para empresas medianas y grandes que necesitan gestión empresarial integral
