# LogiPro — Logística y Gestión de Almacén

**Producto independiente** extraído de la Suite LogiPro.

## Qué incluye

| Módulo | Ruta |
|---|---|
| Dashboard | `/` |
| Mapa del Almacén | `/warehouse-map` |
| Picking / Packing (SGA) | `/sga` |
| Movimientos | `/movements` |
| Seguimiento de Envíos | `/shipping` |
| Transportistas | `/shipping-agencies` |
| Reportes | `/reports` |
| Configuración / Equipo / Facturación | `/settings` `/team` `/billing` |

## Cómo arrancar

```bash
cp products/logi-pro/.env.example .env
npm run dev
```

## Color de marca

- Primario: Naranja `hsl(25, 95%, 50%)`
- Para operadores logísticos, 3PL, almacenes y courier
