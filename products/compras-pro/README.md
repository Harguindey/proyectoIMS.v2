# CompraPro — Gestión de Compras y Proveedores

**Producto independiente** extraído de la Suite LogiPro.

## Qué incluye

| Módulo | Ruta |
|---|---|
| Dashboard | `/` |
| Aprovisionamiento | `/procurement` |
| Proveedores | `/suppliers` |
| Facturas de Compra | `/erp/purchases` |
| Facturas | `/erp/invoices` |
| Reportes | `/reports` |
| Configuración / Equipo / Facturación | `/settings` `/team` `/billing` |

## Cómo arrancar

```bash
cp products/compras-pro/.env.example .env
npm run dev
```

## Color de marca

- Primario: Morado `hsl(262, 80%, 56%)`
- Pensado para departamentos de compras, procurement y gestión de proveedores
